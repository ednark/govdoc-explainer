search-v2 benchmark

Compares the production search setup (fp32 vectors, fetched eagerly on page load) against the v2 experiment (int8 vectors, fetched on first search). Served via npm run serve at /experiments/search-v2/benchmark.html.

Target vectors
1. Payload load (cold / warm)

Fetches fp32 and int8 variants with cache-busting (cold) then again (warm), reporting transfer size and duration from Resource Timing.

2. Embedding model

Time to first usable query embedder (23MB int8 ONNX, one-time, browser-cached). Shared by both variants — measured for completeness.

3. Search latency + ranking agreement

Runs preset queries through both ranking paths (fp32 dot, int8 dot) with 1 warmup + 5 reps each. "Top-8 overlap" is the fraction of shared results between the two paths — the quality proxy.
